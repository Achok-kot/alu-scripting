# API Advanced

This project contains Python scripts that interact with the Reddit API to retrieve and process subreddit data.

## Files

- `0-subs.py`: Function to get the number of subscribers for a subreddit
- `1-top_ten.py`: Function to print the top 10 hot posts for a subreddit
- `2-recurse.py`: Recursive function to get all hot articles for a subreddit
- `3-count.py`: Recursive function to count keywords in hot article titles
